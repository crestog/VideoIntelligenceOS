# ── v2 processing plane (the 30 passes) ──
# torch, numpy and opencv come with the Kaggle image; pinning them here is how
# you break CUDA on a machine you cannot ssh into. Everything below is what the
# image does NOT already carry.
#
# A missing package here is not fatal. Preflight imports each pass's modules and
# reports what is absent; the engine drops those passes from the plan and runs
# the rest. So a failed install costs you passes, not the session.
scenedetect                 # shot boundaries — the atomic unit everything else indexes against
librosa                     # tempo, key, loudness
# librosa asks for numba>=0.61.0, so a plain install resolves it to the newest
# numba there is — and the image's preinstalled cuml-cu12/cudf-cu12 both cap it
# at <0.62. pip installed 0.67.0 anyway and printed a dependency-conflict wall
# at the top of every session while quietly leaving RAPIDS unusable. 0.61.x is
# the one range that satisfies librosa and the image at the same time.
numba>=0.61,<0.62
soundfile                   # wav io for the audio passes
yake                        # keyphrases, statistical rather than prompted
pyannote.audio              # diarisation; also needs an accepted licence + HF token
insightface                 # faces and framing
onnxruntime-gpu             # insightface's runtime
# paddleocr also needs paddlepaddle-gpu, which is a ~700 MB wheel that must match
# the image's CUDA and is deliberately not installed. Without a backend every
# PaddleOCR constructor fails, so `ocr` falls back to EasyOCR (above — already
# installed, already used by the v1 plane on this image) and still reads the
# on-screen text. Install paddlepaddle-gpu by hand if you want PP-OCR itself.
paddleocr
# Florence-2 (`ocr-alt`) is NOT "pure transformers": its remote code does
# `from timm.layers import DropPath, trunc_normal_` at module top level, so
# without timm the class never builds and the pass raised a bare AttributeError
# every run. timm.layers (rather than timm.models.layers) needs 0.9.16 or newer.
# The other half of that failure is flash_attn, which cannot be built on a T4 —
# runners/base.no_flash_attn() strips it from the import check instead.
timm>=0.9.16
